# AGENTS.md

## General Principles
- **Strict User Scope Compliance**: Only make the exact code changes, feature additions, or modifications explicitly requested by the user.
- **No Unsolicited Alterations**: Never remove, rename, add, or alter any UI elements, buttons, or functionality outside the requested task without asking and getting explicit approval from the user first.
- **No Automatic GitHub Pushes**: Do NOT push code to GitHub automatically. Only perform `git push` when the user explicitly commands to update/push GitHub.
